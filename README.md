# DOORA

DOORA is a mobile-first marketplace for everyday small tasks. People can post a task with a clear budget and schedule; nearby people can discover tasks and make offers.

## Stack
- Next.js App Router
- React + TypeScript
- Responsive custom UI
- Lucide icons

## Development
```bash
npm install
npm run dev
```

## Current status
This is the first frontend foundation. Task creation and discovery interactions currently use in-memory demo data and reset on refresh. Authentication, database persistence, messaging, offer management, payment escrow, moderation, and admin tools are not connected yet.

## Product principles
- Mobile-first, app-like interface
- Clear task scope, price, and schedule
- Trust and safety before growth
- Explicit user consent for task completion and payment release
